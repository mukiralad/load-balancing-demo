# Cloud Load Balancer Demo

This project demonstrates cloud load balancing concepts using a Next.js application. It simulates a load balancer distributing traffic across multiple backend servers while providing real-time monitoring and visualization.

## Features

- Interactive load balancer visualization
- Real-time server status monitoring
- Traffic distribution simulation
- Modern, responsive UI using Tailwind CSS

## Getting Started

```bash
# Install dependencies (with legacy peer deps for React 19 compatibility)
npm install --legacy-peer-deps

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
